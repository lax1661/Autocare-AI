# Autocare AI

Cross-platform React Native (Expo) application for vehicle problem diagnosis and offline repair guidance.

## Planned MVP

- Vehicle category and model selection
- Photo and video capture
- Symptom search
- Online diagnosis API
- Offline guides and SQLite data
- Cross-device synchronization
- Saved diagnosis reports
- Mechanic and emergency assistance screens
